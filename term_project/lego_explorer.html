    What the cleaning step did

    Applies the same rules as transform.py: trim text, keep valid whole numbers, derive the minifigure flag from the count, drop exact duplicates.

    Do the themes table and the sets table agree?

    Each theme claims a total_sets. This compares that claim with the sets actually present, both summed per theme group before they are compared.
