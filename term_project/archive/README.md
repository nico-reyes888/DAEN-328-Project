# Archived pre-Docker files

These files are retained for historical/reference purposes. They came from the project before Docker integration and are not used in the final version.

## Contents

- `transform.ipynb` - legacy exploratory notebook for data cleaning.
- `lego_explorer.html` - pre-Docker browser-based LEGO data explorer.
- `projectExtractScript.py` - earlier Kaggle extraction script.
- `test_transform.py` - legacy standalone transform test file.
- `raw/query_1_result.csv` - archived query result.
- `raw/query_2_result.csv` - archived query result.
- `raw/query_3_result.csv` - archived query result.

The supported final implementation is the Docker Compose stack in the parent `term_project` directory.
